### 🤝 Cara Terlibat & Berkontribusi:
1. **💬 Diskusi & Mabar di Discord:** Masuk ke server [Discord SKUAD](https://discord.gg/fQ2FMgF) untuk ngobrol santai seputar teknologi, info game, atau diskusi proyek.
2. **🐛 Laporkan Isu atau Ide:** Menemukan bug atau punya saran fitur baru? Buat *Issue* di repositori proyek terkait.
3. **💻 Kirim Kontribusi (PR):** Fork repositori yang diminati, buat branch baru, kembangkan fitur Anda, dan ajukan *Pull Request*!
